# Asset Pipeline

# Updating assets

1. Install `ffmpeg` globally for audio encoding (`brew install ffmpeg`).

2. Install `imagemagick` globally for image processing (`brew install imagemagick`).

3. Install `pngquant` globally for image processing (`brew install pngquant`).

4. Install `nvm` globally for old node versions (`brew install nvm`).

orphaned.json - logs orphaned files that are not part of the pipeline.
