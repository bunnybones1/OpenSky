# OpenSky Language Manager

## Scripts

- `$ pnpm wordcount` shows total wordcount across game and webapp.
- `$ pnpm sort` sorts all english json translation files.
- `$ pnpm pig` will translate all english into pig latin.
- `$ pnpm crowdin-upload` uploads the english files to CrowdIn. pass an API key as an environment variable.
- `$ pnpm crowdin-download` downloads all translation files from CrowdIn. pass an API key as an environment variable.
