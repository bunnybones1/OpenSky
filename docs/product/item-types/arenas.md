# Arenas

Arenas are the presentation environments in which [matches](../activities/matches/README.md) take place.

## Role in the Product

An arena frames the battlefield visually. It provides the stage for the board, the players' sides, and the surrounding environment without changing the underlying match rules.

## Presentation Elements

Typical arena presentation includes:

- the split battlefield layout for both players
- visible board zones such as deck, graveyard, and field areas
- environmental effects such as day/night transitions used to reinforce match state or turn ownership
