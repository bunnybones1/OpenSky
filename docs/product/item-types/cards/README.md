# Cards

Cards are the core collectible and playable item type in OpenSky.

## Main Card Types

- [Characters](./characters.md): persistent battlefield bodies, including heroes and units
- [Spells](./spells.md): one-shot or temporary effects played from hand

Every card is defined by a common set of [properties](./properties/README.md), with some properties only applying to specific card families.

## Attachment Rules

OpenSky supports attached spell cards on certain character cards. An attached spell can only be used while its host character remains on the field.
