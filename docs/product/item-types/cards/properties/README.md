# Card Properties

Most cards share a common set of properties, with a few exceptions for heroes and special card types.

Property | Notes
--- | ---
[Grade](./grade.md) | Collectibility and ownership quality
[Mana Cost](./mana-cost.md) | Not used by heroes
[Prism](./prism.md) | Heroes can have two prisms or use elemental affinity instead
[Element](./elements.md) | Heroes do not use elemental identity in the normal card sense
[Traits](./traits/README.md) | Keyword-like identity groupings and synergies
[Card Effects](./card-effects/README.md) | Play text and rule behavior; heroes use hero abilities instead

Some card families also introduce additional type-specific properties.
