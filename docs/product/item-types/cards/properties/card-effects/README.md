# Card Effects

Most cards have a text description, which describes the card effect.
Card effects can be or do almost anything!

Card effects can have any number of the following:

- [Triggers](./triggers.md)
- [A Play Target](./play-target.md)
- [Unit Auras](./unit-auras.md)
- [Auras](./auras.md)
- [Cost Formulas](./cost-formulas.md)
