# Decks

A deck is a saved collection of [cards](./cards/README.md) built for use in [matches](../activities/matches/README.md).

## Role in the Product

Decks are the bridge between a player's collection and actual play. They package card choices into a reusable loadout that can be selected, edited, and brought into match queues.

## Design Implications

Deckbuilding rules determine what cards can coexist in a deck, which in turn makes decks one of the main places where prism identity, collection depth, and metagame knowledge become visible.
