# Item Types

Item Type | Description
--- | ---
[Cards](./cards/README.md) | Core collectible gameplay objects used in matches and deckbuilding
[Decks](./decks.md) | Saved collections of cards used for match play
[Cardbacks](./cardbacks.md) | Cosmetic backs applied to a player's cards
[Stickers](./stickers.md) | Match-time cosmetic emotes
[Gems](./gems.md) | Premium currency and monetization-facing value store
[Titles](./titles.md) | Player-facing profile or status banners
[Spark](./spark.md) | Non-tradeable progression currency used by the current economy
[Arenas](./arenas.md) | Match presentation environments
