# Narrative

Event-driven story arcs and scenario hooks set within the world of Sky.

## Story Arcs

- [Clash of Inventors](./clash-of-inventors.md): A Kore City invention festival where brilliance, rivalry, and spectacle collide.
- [Hexbound Invasion](./hexbound-invasion.md): A set-piece conflict centered on the spread of the Hexbound curse across Sky.
- [The Glitch Storm](./the-glitch-storm.md): A narrative frame for the reality-warping storm that distorts lands, lives, and history.
