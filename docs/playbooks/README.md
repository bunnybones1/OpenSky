# Playbooks

Playbooks are coordination checklists for recurring multi-step operations that usually span design, engineering, content, QA, and release communication.

Playbook | Typical cadence | Purpose
--- | --- | ---
[Balance Patches](./balance-patches.md) | every few weeks | Coordinate a balance-only patch from design changes through release comms
[New Skypass Seasons and Rebalance](./new-skypass-seasons-and-rebalance.md) | every 28 days | Coordinate a season rollover that also carries balance and reward changes
