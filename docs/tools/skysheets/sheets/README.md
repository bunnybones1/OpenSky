# Sky Sheets Tables

Table | Description
--- | ---
[Cards](./cards.md) | Card definitions, metadata, text, and linked art references
Art | Card-related art records and the assets they map to
Vocab | Vocabulary and tooltip rules used in card text rendering
Quests | Quest definitions and reward-relevant metadata
Crystals | Crystal-related design data
Hero Skins | Hero skin definitions and related metadata
[Card Backs](./cardbacks.md) | Cardback data and presentation metadata
[Stickers](./stickers.md) | Sticker definitions and seasonal usage data
[Titles](./titles.md) | Title definitions and display text
Invite-a-friend Sticker Schedule | Scheduling data for invite-a-friend sticker rewards

When new art is added directly to `OpenSky-assets`, you can populate art-sheet records with [populate-art](../scripts/populate-art.md).
