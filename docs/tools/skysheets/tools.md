# Sky Sheets Tools

Tool | Description
--- | ---
Toggle Theme | Switch between available UI themes
Toggle Brainstorm | Temporarily relax editor-side validation for ideation; build validation still applies
Reload | Reload the app without restarting the whole process
Open DB Folder | Open the backing design-data folder in the OS file browser
Reset Layout to Default | Restore the default panel layout
Log Layout Model to Console | Debug layout state for development issues
Assets Config | Choose whether art previews resolve against local or remote assets
