# Populate Art

A script to automate adding new art to [Sky Sheets](../README.md).

Assuming new art was added directly to `OpenSky-assets` and new art previews were generated via the [Asset Pipeline](../../asset-pipeline.md), running this script will ensure that all art with art previews is on the art/pixel/cartoon sheet.

## Usage
`cd design-data && pnpm populate-art`
