## How To Use These Docs

- Prefer the contributor-facing operational docs for current setup and maintenance work.
- Treat product and lore docs as reference material, not deployment instructions.
- When code and docs diverge, update the docs to describe the current supported behavior or clearly mark the gap.

## Editorial Standard

These docs aim to describe the current public repository as it exists today.

Some historical pages still preserve older process context or partial coverage, but the goal is a coherent contributor-facing reference set rather than an internal planning archive.
